# RcTab

Class `RcTab` extends [`WComponent`](WComponent.md) · element `<rc-tab>` · group `ui` · source [`src/ui/rc-tabs.mjs`](../../src/ui/rc-tabs.mjs)

The component of `<rc-tab>`: the content of one tab. Its attributes are read by `rc-tabs`.

## Interface

| Kind | Name | Direction | Payload | Description |
| --- | --- | --- | --- | --- |
| attribute | `value` | in | `string` | Value of the tab; default: its label. |
| attribute | `label` | in | `string` | Title in the bar. |
| attribute | `icon` | in | `string` | Icon before the title. |
| attribute | `title` | in | `string` | Tooltip of the title. |
| attribute | `disabled` | in | `boolean` | The tab cannot be shown. |
