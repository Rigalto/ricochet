# RcCheckbox

Class `RcCheckbox` extends [`RcIconButton`](RcIconButton.md) · element `<rc-checkbox>` · group `ui` · source [`src/ui/rc-checkbox.mjs`](../../src/ui/rc-checkbox.mjs)

The component of `<rc-checkbox>`.

## Methods

### get value

The state: `yes` or `no`.

### keptChanged(value)

The value kept in the item (`data-item`) or the field (`data-field`) changed: the box shows it. Not set yet: the
initial state stays.

| Parameter | Type | Description |
| --- | --- | --- |
| `value` | string\|undefined\|null | `yes` or `no`. |
