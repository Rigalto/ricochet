Règles de confidentialité

Applications publiées sur rigalto.github.io (SweetHome, démonstrations de Ricochet) — 6 novembre 2026

Ces applications sont des projets personnels, utilisés par leur auteur et quelques proches. Elles fonctionnent entièrement dans votre navigateur : il n'y a aucun serveur qui recevrait ou conserverait vos données.

Les données auxquelles l'application accède

  • Votre adresse e-mail Google : pour afficher le compte connecté et le reproposer lors d'une reconnexion.
  • Google Drive (autorisation drive.file) : uniquement les fichiers que l'application a créés, ou que vous avez vous-même ouverts avec elle. Elle ne voit pas vos autres fichiers.
  • Google Tasks : vos listes et vos tâches, pour les afficher et les modifier à votre demande. Cet accès n'est demandé que si vous ouvrez une fonction qui en a besoin.

Où vont ces données

  • Les échanges ont lieu directement entre votre navigateur et Google. Les données restent dans votre compte Google.
  • Le jeton d'accès donné par Google est gardé dans votre navigateur seulement. Il n'est envoyé qu'à Google.
  • L'application peut garder une copie de travail de vos données dans votre navigateur, pour démarrer plus vite. Elle est effacée quand vous vous déconnectez de l'application.
  • Aucune donnée n'est vendue, partagée, transmise à un tiers, ni utilisée pour de la publicité ou pour entraîner un modèle d'intelligence artificielle.

L'utilisation et le transfert vers toute autre application des informations reçues des API Google respectent les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Retirer l'accès

  • Dans l'application : « Se déconnecter et retirer l'accès ».
  • Ou à tout moment dans votre compte Google : myaccount.google.com/connections.

Code source et contact

Le code du noyau est public : github.com/Rigalto/ricochet. Pour toute question, ouvrez une demande sur ce dépôt.
