Ricochet

A zero-dependency JavaScript kernel where components react to events, act on their own DOM, and emit events. No virtual DOM, no build step.

Use it

Ricochet lives in your project: add it as a Git submodule or a copy, and it is published with your application. You choose when to update, and nothing depends on a third-party server. This site shows the latest code, for the demos and the documentation. See the guide.
